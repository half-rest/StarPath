# StarPath
* 창원대학교 2026-2학기 정보보안 과제
* 5조 (폴리곤) - 명세진, 이재성, 이지원, 임수민, 김진용

## 파일 구성
* `shared.py` - 공유 코드
* `keygen.py` - 키 생성 코드
* `encrypt.py` - 암호화 코드
* `decrypt.py` - 복호화 코드
* `roles.py` - 역할 코드
* `web_demo.py`, `web/index.html` - 웹 시연 코드

## 실행
```
pip install cryptography
python web_demo.py   # 웹 시연 → http://127.0.0.1:8000
```
